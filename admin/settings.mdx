Settings is where organization and workspace configuration lives. The page has six tabs: **Providers**, **Team**, **Channels**, **User Groups**, **Account**, and **Audit Log** (admin-only).

Page description in the app reads: _"Chat providers, team, channels, user groups, account, and audit."_

## The six tabs

### Providers

The chat providers configured for your organization (Slack and Microsoft Teams). Use this tab to see connected providers and to reconnect if a token expired.

### Team

Team members and their roles. See [Roles & Access](/get-started/roles-and-access) for what Owner, Admin, and Member can each do.

### Channels

The channels Corunner operates in. Adding a channel lets Corunner respond to `@Corunner` mentions there and lets standups and other automated posts run in it.

### User Groups

Group team members so agents can address a group instead of an individual (for example, "@Corunner tell #on-call there's an incident"). Groups also feed governance and standup targeting.

### Account

Organization-level account details.

### Audit Log (admin-only)

An audit trail of admin actions, integration changes, and other org-level events. Members do not see this tab; the backend also blocks the underlying data for non-admins.
