Jira & Confluence is a single Direct Connection built as an Atlassian **Forge app**. Installing it once gives Corunner access to both Jira and Confluence for your Atlassian site, so you do not have to connect them separately.

## What Corunner does with Jira and Confluence

Agents read and act on your Jira issues (sync status, file new tickets, transition workflow) and read and update Confluence pages so decisions and specifications stay current. `@Corunner` mentions inside Jira issues and Confluence pages are routed back to the agents in your chat workspace.

## What you get

- Read Jira issues
- Create Jira issues
- Update Jira status
- Read Confluence pages
- Update Confluence pages
- Respond to `@Corunner` mentions inside Atlassian

## Authentication

Corunner ships as an Atlassian Forge app. Install it from the Atlassian Marketplace, then paste the verification code shown in the connection card into the Corunner integrations page to link it.

## What breaks if you disconnect

- Issue sync
- Blocker tracking
- Atlassian `@Corunner` mentions

## Manage this connection

Open **Integrations** in the Corunner web app, then find **Jira & Confluence** under the **Direct Connections** tab.

## Install the Corunner Forge app

Open the **Connect Jira & Confluence** dialog. Corunner generates a verification code for linking the Atlassian installation to your Corunner workspace.

<Frame caption="Start the Jira and Confluence installation from Corunner.">
  ![Connect Jira and Confluence dialog showing the install button, setup steps, and verification code](/images/integrations/direct/jira/jira.png)
</Frame>

The verification code is single-use and remains valid for 15 minutes. If it expires, generate a new code before continuing. Each request from the Forge app is verified using an Atlassian-signed invocation token. The code alone cannot link an installation.

<Frame caption="Review the verification-code status and security information in Corunner.">
  ![Connect Jira and Confluence dialog showing the verification code, refresh status button, expiration notice, and invocation-token information](/images/integrations/direct/jira/jira1.png)
</Frame>

## Sign in to Atlassian

Click **Install the Corunner app in Jira & Confluence**. Corunner opens the Atlassian Marketplace flow. If you are not already signed in, Atlassian asks you to log in.

<Frame caption="Log in to Atlassian to continue installing the Corunner app.">
  ![Atlassian login page with email, passkey, and Google sign-in options](/images/integrations/direct/jira/jira2.png)
</Frame>

<Steps>
  <Step title="Log in to Atlassian">
    Enter the email address for your Atlassian account and click **Continue**. You can also use a passkey or Google sign-in if your organization supports it.
  </Step>
  <Step title="Install the Corunner app">
    Select the Atlassian site that contains the Jira and Confluence data you want Corunner to access. The list only includes sites where you are an admin.

    If Atlassian shows **You aren’t currently an admin of any sites**, sign in with an account that has admin access or ask your Atlassian site admin to install the app.

    Review the app permissions and vendor details, then click **Install**. Confirm that **Installation successful** appears for both Jira and Confluence.

    <Frame caption="Confirm successful installation for Jira and Confluence on your selected site.">
      ![Atlassian installation dialog showing the selected site and successful installation for Jira and Confluence](/images/integrations/direct/jira/jira3.png)
    </Frame>
  </Step>
  <Step title="Open the Corunner admin page">
    In Jira, click the three-dot menu next to **Apps**, then select **Manage apps** to find the installed Corunner app. Open the Corunner admin page to link your workspace.

    <Frame caption="Open Manage apps from the Apps menu in Jira.">
      ![Jira sidebar with the Apps menu open and the Manage apps option visible](/images/integrations/direct/jira/Jira4.png)
    </Frame>
  </Step>
  <Step title="Verify the connection">
    Paste the verification code from the **Connect Jira & Confluence** dialog into the **Verification code** field on the Corunner admin page. Click **Connect** to link this Atlassian site to your Corunner workspace.

    <Frame caption="Enter your verification code and connect the Atlassian site to your Corunner workspace.">
      ![Corunner admin page showing the Verification code field, Connect button, and 15-minute code expiration notice](/images/integrations/direct/jira/jira5.png)
    </Frame>

    Return to the Corunner dialog and click **Refresh status** to confirm the connection.
  </Step>
</Steps>

<Tip>
  If the code expires before you finish, return to Corunner and generate a new one. Do not reuse a code from an earlier installation attempt.
</Tip>
