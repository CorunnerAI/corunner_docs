Confluence is a Direct Connection built as an Atlassian **Forge app**. Install the Corunner Confluence app on an Atlassian site, then link that installation to your Corunner workspace.

## What Corunner does with Confluence

- Read Confluence page content and summaries
- Update Confluence pages
- Keep decisions and specifications current
- Respond to `@Corunner` mentions in Confluence

## Before you start

You need administrator access to the Atlassian site where you want to install the app. The installation flow only lists sites where you are an admin.

Corunner generates a single-use verification code that expires after 15 minutes. Keep the **Connect Confluence** dialog open while you complete the Atlassian installation.

## Manage the connection

Open **Integrations** in the Corunner web app, then find **Confluence** under the **Direct Connections** tab. Select **Connect Confluence** to start the installation or to generate a new verification code.

## Install and connect the Corunner Confluence app

Open the **Connect Confluence** dialog in Corunner.

<Frame caption="Start the Confluence installation from Corunner.">
  ![Connect Confluence dialog showing the Confluence installation steps and verification code](/images/integrations/direct/jira/confluence.webp)
</Frame>

Click **Install the Corunner app in Confluence**. Corunner opens the Atlassian Marketplace flow in a new tab.

<Steps>
  <Step title="Sign in to Atlassian">
    Enter the email address for your Atlassian account and click **Continue**. You can also use a passkey or Google sign-in if your organization supports it.

    <Frame caption="Sign in to your Atlassian account before installing the Confluence app.">
      ![Atlassian sign-in page with the email field and Continue button](/images/integrations/direct/confluence/confluence-1.png)
    </Frame>
  </Step>
  <Step title="Review the app and install it">
    Review the app name, vendor details, and requested Confluence permissions. The app needs permission to read Confluence content summaries and write Confluence content. Click **Get app** to continue to site selection.

    <Frame caption="Review the Corunner Confluence app details and permissions.">
      ![Atlassian Marketplace page for Corunner Confluence showing its permissions and the Get app button](/images/integrations/direct/confluence/confluence-3.webp)
    </Frame>
  </Step>
  <Step title="Choose your Confluence site">
    On the installation page, choose the Atlassian site where you want to install **Corunner Confluence**. The page only lists sites where you are an administrator. Click **Install** after you select a site.

    <Frame caption="Choose the Atlassian site for the Corunner Confluence app.">
      ![Corunner Confluence installation page with the site selector](/images/integrations/direct/confluence/confluence-2.webp)
    </Frame>
  </Step>
  <Step title="Open the Corunner admin page">
    In Confluence, open **Apps**, select the three-dot menu, and click **Manage apps**. Find Corunner Confluence and open its admin page.

    <Frame caption="Open Manage apps from the Confluence Apps menu.">
      ![Confluence Apps menu with the Manage apps option visible](/images/integrations/direct/confluence/confluence-4.png)
    </Frame>
  </Step>
  <Step title="Verify the connection in Corunner">
    Copy the verification code from the **Connect Confluence** dialog. Paste it into the **Verification code** field on the Corunner admin page and click **Connect**. Return to Corunner and click **Refresh status**.

    <Frame caption="Enter the Corunner verification code to link Confluence.">
      ![Corunner Confluence admin page with the Verification code field and Connect button](/images/integrations/direct/confluence/confluence-5.png)
    </Frame>

    The dialog also shows the code expiration time and explains that the code links the Confluence installation to your Corunner workspace.
  </Step>
</Steps>

<Tip>
  The verification code is single-use and expires after 15 minutes. If it expires or you use it unsuccessfully, return to Corunner and generate a new code.
</Tip>

## Troubleshooting

- If your site does not appear in the Atlassian site selector, confirm that you are an administrator for that site.
- If installation is blocked, review the app permissions and your organization's Atlassian app-installation policy.
- If Corunner still shows **Not connected yet**, confirm that you pasted the code into the Corunner Confluence admin page, then click **Refresh status**.

## What happens if you disconnect

Disconnecting Confluence stops page search, page updates, decision and specification context, and Confluence `@Corunner` mentions. It does not delete your Confluence pages.
