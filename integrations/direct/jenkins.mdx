Jenkins is a Direct Connection that lets Corunner watch builds and jobs on your Jenkins server. Once connected, agents can surface build status and pipeline health in chat without your team checking Jenkins directly.

## What Corunner does with Jenkins

Agents read jobs and builds so the team hears about failures and unhealthy pipelines in the channels they already use. Build history also feeds the Debug/Diagnostics Agent when it correlates recent build changes with incidents.

## What you get

- Read jobs
- Read builds

## Authentication

Connect with an API key you generate in Jenkins. Paste it into the connection card in Corunner alongside the Jenkins server URL.

## What breaks if you disconnect

- Build status
- Pipeline health

## Manage this connection

Open **Integrations** in the Corunner web app, then find **Jenkins** under the **Direct Connections** tab.
