CircleCI is a Direct Connection that lets Corunner read pipelines and workflows from your CircleCI project. Once connected, agents surface build status and deploy activity in chat.

## What Corunner does with CircleCI

Agents watch pipelines and workflows so the team knows immediately when something breaks in CI or when a deploy completes. Pipeline history also feeds root-cause analysis when the Debug/Diagnostics Agent looks into incidents.

## What you get

- Read pipelines
- Read workflows

## Authentication

Connect with an API key (personal token) you generate in CircleCI. Paste it into the connection card in Corunner.

## What breaks if you disconnect

- Build status
- Deploy tracking

## Manage this connection

Open **Integrations** in the Corunner web app, then find **CircleCI** under the **Direct Connections** tab.
