Bitbucket is a Direct Connection that lets Corunner read repositories, pull requests, and commits in Bitbucket Cloud. It ships as an Atlassian **Forge app**, so you install it from the Atlassian Marketplace and link it to Corunner using a verification code.

## What Corunner does with Bitbucket

Agents watch pull requests, comment where appropriate, and track deployments so your team gets PR signals and review-load insights without leaving chat.

## What you get

- Read repos
- Read pull requests
- Read commits
- Comment on PRs

## Authentication

Corunner ships as an Atlassian Forge app. Install it from the Atlassian Marketplace, then paste the verification code from Corunner into **Corunner Setup** in Bitbucket to link it.

## What breaks if you disconnect

- PR signals
- Review-load insights
- Deploy tracking

## Manage this connection

Open **Integrations** in the Corunner web app, then find **Bitbucket** under the **Direct Connections** tab.

## Install the Corunner Forge app

Open the **Connect Bitbucket** dialog. Corunner generates a verification code for linking the Bitbucket installation to your Corunner workspace.

<Frame caption="Start the Bitbucket installation from Corunner.">
  ![Connect Bitbucket dialog showing the install button, setup steps, and verification code](/images/integrations/direct/bitbucket/bitBucket.png)
</Frame>

The verification code is single-use and remains valid for 15 minutes. If it expires, generate a new code before continuing. Each request from the Forge app is verified using an Atlassian-signed invocation token. The code alone cannot link an installation.

<Frame caption="Review the verification-code status and security information in Corunner.">
  ![Connect Bitbucket dialog showing the verification code, refresh status button, expiration notice, and invocation-token information](/images/integrations/direct/bitbucket/bitBucket1.png)
</Frame>

## Sign in to Atlassian

Click **Install the Corunner app in Bitbucket**. Corunner opens the Atlassian Marketplace flow. If you are not already signed in, Atlassian asks you to log in.

<Frame caption="Log in to Atlassian to continue installing the Corunner app for Bitbucket.">
  ![Atlassian login page with email, passkey, and Google sign-in options](/images/integrations/direct/jira/jira2.png)
</Frame>

<Steps>
  <Step title="Log in to Atlassian">
    Enter the email address for your Atlassian account and click **Continue**. You can also use a passkey or Google sign-in if your organization supports it.
  </Step>
  <Step title="Install the Corunner app">
    Select the Bitbucket Cloud workspace you want Corunner to access. The selection list only includes sites where you are an admin. Review the app permissions and vendor details, then approve the installation. Confirm that **Installation successful** appears for Bitbucket.

    <Frame caption="Confirm the Corunner app is installed in your selected Bitbucket workspace.">
      ![Corunner Bitbucket installation dialog showing the selected workspace and Installation successful status](/images/integrations/direct/bitbucket/bitbucket2.png)
    </Frame>
  </Step>
  <Step title="Accept the requested access">
    Review the permissions on the Atlassian access page. Scroll to the bottom and click **Accept**. You are then redirected to Bitbucket.

    <Frame caption="Review the requested permissions, then scroll down to Accept.">
      <img src="/images/integrations/direct/bitbucket/bitBucket3.png" alt="Atlassian page showing Corunner - Bitbucket requesting access to your account and Bitbucket data" />
    </Frame>
  </Step>
  <Step title="Open workspace settings">
    In Bitbucket, click the **Settings** gear icon in the top-right corner. Select **Workspace settings** under **Bitbucket Administration**.

    <Frame caption="Open Workspace settings from the Bitbucket Settings menu.">
      ![Bitbucket Settings menu with Workspace settings under Bitbucket Administration](/images/integrations/direct/bitbucket/bitBucket4.png)
    </Frame>
  </Step>
  <Step title="Open Corunner Setup">
    In the workspace settings sidebar, expand **Forge Apps**. Under **Corunner - Bitbucket**, click **Corunner Setup**.

    <Frame caption="Select Corunner Setup under Forge Apps.">
      ![Workspace settings sidebar showing Corunner Setup under Forge Apps and Corunner - Bitbucket](/images/integrations/direct/bitbucket/bitBucket5.png)
    </Frame>
  </Step>
  <Step title="Allow access">
    If Corunner Setup asks for permission to access Atlassian products on your behalf, click **Allow access** to continue to the verification-code form.

    <Frame caption="Allow access so Corunner Setup can display the connection form.">
      ![Corunner Setup permission notice with the Allow access button](/images/integrations/direct/bitbucket/bitBucket6.png)
    </Frame>
  </Step>
  <Step title="Verify the connection">
    Copy the verification code from the **Connect Bitbucket** dialog in Corunner, shown in the first screenshot on this page. Paste it into the **Verification code** field in **Corunner Setup**, then click **Connect** to link your Bitbucket workspace to your Corunner workspace.

    <Frame caption="Paste the verification code from Corunner and click Connect.">
      ![Corunner Setup connection form with the Verification code field and Connect button](/images/integrations/direct/bitbucket/bitBucket7.png)
    </Frame>

    Return to the Corunner dialog and click **Refresh status** to confirm the connection.
  </Step>
</Steps>

<Tip>
  If the code expires before you finish, return to Corunner and generate a new one. Do not reuse a code from an earlier installation attempt.
</Tip>
