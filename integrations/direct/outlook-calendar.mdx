Outlook Calendar is a Direct Connection that lets Corunner read Microsoft 365 calendars and availability. Once connected, agents have meeting context and can respect busy blocks when scheduling or routing work.

## What Corunner does with Outlook Calendar

Agents read events and availability so they can answer scheduling questions, feed context into standups, and place reminders that do not collide with meetings.

## What you get

- Read events
- Read availability

## Authentication

Connect with OAuth. A Microsoft 365 admin approves the scopes during the connect flow.

## What breaks if you disconnect

- Meeting context
- Availability awareness

## Manage this connection

Open **Integrations** in the Corunner web app, then find **Outlook Calendar** under the **Direct Connections** tab.
